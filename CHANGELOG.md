# Changelog

Все заметные изменения BIKESETUP. Формат — по мотивам [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии — [SemVer](https://semver.org/lang/ru/).

## [0.1.2] — 2026-11-16

Версия движка расчёта: **1.7.0** (было 1.5.0). Давления теперь считаются от комнатной
температуры и показывают, сколько качать дома. В сетап добавлен выбор «Где кататься».

### Исправлено

**Профиль райдера больше не сбрасывается при обновлении.**

В версии 0.1.1 хранилище было версии 1, в 0.1.2 появилась миграция до версии 2.
Она убирала демо-байк Norco, но заодно принудительно ставила профилям `rider_demo`
и `rider_default` значения 175 см / 75 кг / 3 кг. Из-за этого после запуска новой
сборки имя оставалось, а рост, вес и экипировка слетали к демо-значениям.

Теперь миграция только удаляет демо-байк и его сетапы, профиль райдера не трогает.
Версия хранилища поднята до 3. Если профиль уже успел сброситься, верните свои
значения в разделе «Райдер» вручную или восстановите их из резервной копии.

**Температура накачки стала явной.**

Раньше давление в шинах получало приблизительную поправку `(20 − T) × 0.1 psi`, а в
интерфейсе не было сказано, к какой температуре относится число: качать дома или на
улице. Вилка компенсировала холод множителем 0.34% на °C, аморт — вообще без поправки.

Теперь:

- Целевое давление считается для улицы при текущей температуре из шага «Условия».
- Давление для накачки пересчитывается на домашние +20 °C по закону Гей-Люссака по
  абсолютному давлению: `(P + 14.7) × Tдома / Tулицы − 14.7`.
- В карточках видны оба числа: «дома +20 °C → 27 psi» и «на улице 0 °C → 24 psi».
- Пересчёт применяется к шинам, воздушной вилке и воздушному аморту.
- Пример: чтобы получить 24 psi на улице при 0 °C, дома при +20 °C нужно 26.8 ≈ 27 psi.
- Сэг в карточках — целевой на улице. Проверяйте его после стабилизации температуры,
  а не сразу после накачки дома.
- Ранее сохранённые сетапы остаются снимками старых расчётов; новые считаются по
  версии 1.7.0.

### Добавлено

**Выбор «Где кататься».**

Дисциплина байка описывает сам байк, но не место катания: на трейловом байке можно
поехать в байк-парк, а на гравийном — по асфальту. Теперь в шаге «Условия» есть
отдельный селект «Где кататься». Он даёт поправку только к давлению в шинах, чтобы не
дублировать ползунок «Характер трейла» (технично ↔ флоу), который отвечает за сэг и
токены.

| Покрытие                     | Поправка к шинам |
| ---------------------------- | ---------------- |
| Асфальт / город              | +3.0 psi         |
| Гравий / грунтовки           | +1.5 psi         |
| Укатанный грунт / трейлы    | 0.0 psi          |
| Мягкий лес / листва          | −0.5 psi         |
| Корни и камни                | −1.0 psi         |
| Эндуро-трейлы                | −1.5 psi         |
| ДХ / байк-парк               | −2.0 psi         |
| Дёрт / памп-трек             | +2.0 psi         |
| Песок / пляж                 | −3.5 psi         |

- Если покрытие не выбрано (старые сетапы и ссылки), подставляется типичное для
  дисциплины байка: XC и trail — укатанный грунт, enduro — эндуро, DH — байк-парк,
  dirt — дёрт, gravel — гравий.
- Выбор сохраняется в сетапе, попадает в ссылки и коды обмена.
- Поправка складывается с погодой, типом посадки, вставкой и нагрузкой на колесо.

### Интерфейс

- В шаге «Условия» появился селект «Где кататься» с пояснением и величиной поправки.
- В сводке сетапа и в истории показывается выбранное покрытие.
- Ползунок «Тип трейла» переименован в «Характер трейла», чтобы не путать с покрытием.
- В карточках вилки, аморта и шин подписано «Давление дома» и добавлено давление на
  улице.
- В шаге «Позиция райдера» и в истории сетапов давления помечены как домашние.
- В блоке «Как это посчитано» показана цепочка: целевое давление на улице → поправка
  на +20 °C → давление для накачки, а также поправка на покрытие.
- Пояснение в сводке больше не советует «измерять на улице»: давление в карточках —
  для накачки дома, сэг проверяется на улице.

### Проверка

- Пример 24 psi на улице при 0 °C даёт 26.8 ≈ 27 psi дома при +20 °C.

- Переключение покрытия меняет давление в шинах на величину поправки; на вилку и
  аморт покрытие не влияет.

## [0.1.1] — 2026-11-15

Версия движка расчёта: **1.5.0** (было 1.4.2). Исправление расчёта и новая настройка шин.

### Исправлено

**Позиция райдера теперь влияет на давление.**

Раньше ползунок «Позиция райдера» менял только карточку развесовки, а давления
оставались прежними: в формулах вилки, аморта и шин использовался неизменный вес
райдера в экипировке, а реальная нагрузка на переднее и заднее колесо в расчёт не
попадала. Исключением была только пружинная вилка.

- Добавлены множители нагрузки относительно нейтральной стойки: `frontLoadF` и
  `rearLoadF`.
- Множители учитываются в давлении воздушной вилки, давлении воздушного аморта,
  подборе жёсткости пружины аморта и давлении в шинах (переднее и заднее отдельно).
- Отклик нелинейный, чтобы не завышать поправку: подвеска — степень 0.85, шины — 0.7.
- При позиции 0 мм множители равны 1, поэтому старые значения не изменились:
  калибровка «psi ≈ вес» сохранена.
- В блок «Как это посчитано» добавлены строки про нагрузку.

Пример для трейл-байка 150/140 мм, покрышки 2.4″, райдер 75 кг + 3 кг экипировки,
сухо, +18 °C:

| Позиция | Нагрузка перед / зад | Вилка  | Аморт   | Шины перед / зад  |
| ------- | -------------------- | ------ | ------- | ----------------- |
| −60 мм  | 31.0 / 61.0 кг       | 70 psi | 195 psi | 26.0 / 32.5 psi   |
| 0 мм    | 35.5 / 56.5 кг       | 78 psi | 180 psi | 29.0 / 31.0 psi   |
| +60 мм  | 40.1 / 51.9 кг       | 87 psi | 170 psi | 31.5 / 29.0 psi   |

### Добавлено

**Тип посадки покрышки.** Раньше приложение всегда считало давление «для
бескамерки». Теперь тип посадки выбирается отдельно для переднего и заднего колеса.

| Вариант                                       | Поправка |
| --------------------------------------------- | -------- |
| Камера (butyl)                                | +2.0 psi |
| Камера TPU / латекс                           | +1.0 psi |
| Бескамерка, крючковатый обод (crochet)         | 0.0 psi  |
| Бескамерка, прямой обод (hookless / TSS)      | −0.5 psi |
| Трубка (tubular)                              | −1.0 psi |

- Где выбрать: Байк → «Колёса и шины» → блок «Переднее» / «Заднее» → «Тип посадки».
  Под селектом показывается короткое пояснение для выбранного варианта.
- Вставка (CushCore и подобные) учитывается только для бескамерки и трубки. С
  камерой вставка не ставится: галочка снимается автоматически при смене типа
  посадки. Если в старом сетапе осталась вставка с несовместимым типом, в
  «Проверках» появляется пояснение, что поправка −2 psi не применена.
- Обратная совместимость: поле `tireSetup` необязательное. Байки и ссылки без него
  считаются бескамеркой, то есть цифры у них не меняются. Общие ссылки и бэкапы
  переносят тип посадки автоматически.

### Интерфейс

- Шаг 4 «Позиция райдера»: в блоке с развесовкой добавлены строки «Давление вилки»
  и «Шины перед / зад» — видно, как стойка меняет цифры.
- Шаг 1 «Байк»: добавлена строка «Посадка шин» (например, tube / tubeless).
- Карточка «Шины»: бейдж показывает реальный тип (TUBE, TUBELESS, HOOKLESS,
  TUBULAR, TPU; при разном типе спереди и сзади — через слэш).
- В плитке каждого колеса подпись типа посадки.
- В редакторе байка подсказка у вставки меняется в зависимости от посадки.

### Прочее

- Формула давления в шинах переписана со знаками слагаемых («+ 2.0» / «− 1.2»),
  чтобы отрицательные поправки читались нормально.
- README дополнен разделами про влияние стойки и про типы посадки.
- Новые байки и пресеты дисциплин создаются с типом посадки «бескамерка».
- Версия приложения поднята до 0.1.1 (`package.json`, `package-lock.json`,
  `CONTRIBUTING.md`), скриншоты в README пересобраны на 0.1.1.
